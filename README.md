# Сервант для Спектры — чертежи из палитурного картона

Два кукольных шкафа (витрина + тумба) под куклу Monster High 28 см. Картон 2 мм, полки 3 мм, склейка торец к плоскости термоклеем.

- `chertezhi.html` — фасад, разрезы, дверца, ящик, карта деталей, порядок сборки.
- `shablony-1-1.pdf` — шаблоны деталей в масштабе 1:1 (печатать при 100 %, на каждой странице контрольная линейка 10 см).
- `generator/build.py` — генератор обоих файлов; все размеры в нём, поменять и перезапустить: `pip install reportlab && python3 generator/build.py`.

Ключевые размеры (компактная версия): высота 30 см, ширина 12,4 см, глубина витрины 5 / тумбы 6 см, между боками 12 см, полка между шкафами 7,4 см. Все подписи на чертежах и в PDF в сантиметрах; в коде генератора размеры хранятся в мм.

## Текстуры для оклейки

`tekstury-a4.pdf` — три листа A4 (300 dpi) с текстурой древесины для печати на самоклеящейся бумаге: 1 фасады (тёмный орех), 2 ниша и полки (средний орех), 3 наружные бока и цоколь (светлый ламинат). Волокна вдоль длинной стороны листа. Генератор: `pip install numpy scipy pillow && python3 generator/textures.py` (PNG-версии складываются в `textures/`).
